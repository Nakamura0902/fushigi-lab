プライバシーポリシー

最終更新日: 2026年11月19日

FUSHIGI LAB STUDIO（以下「本ツール」）は、YouTube チャンネル「フシギの検証室」の運営者が、自分のチャンネルを管理するためだけに使う個人用のツールです。第三者には提供していません。

1. 取得する情報

運営者が Google アカウントで接続したときに限り、Google API（YouTube Data API、YouTube Analytics API）を通じて、次の情報を取得します。

  • 運営者自身のチャンネルの基本情報（チャンネル ID、名前、登録者数など）
  • 運営者自身のチャンネルの動画の情報と、その再生数・視聴時間などの統計
  • 接続を維持するための認証トークン

2. 利用目的

  • 運営者が自分のチャンネルの状況を確認し、動画の制作計画を立てるため
  • 運営者が承認した動画を、非公開でアップロードし、予約投稿するため

3. 保存と管理

取得した情報は、運営者の PC の中にだけ保存します。外部のサーバーには送信・保存しません。認証トークンは暗号化して保存します。

4. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。広告にも使いません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

本ツールは YouTube API サービスを利用しています。YouTube 利用規約と Google プライバシーポリシーもあわせてご確認ください。

6. 接続の解除と削除

本ツールの画面の「切断する」で、保存した認証トークンを削除できます。また、Google アカウントの「サードパーティのアクセス」からいつでもアクセス権を取り消せます。

7. 連絡先
